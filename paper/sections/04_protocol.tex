\subsection{Design principles}\label{sec:principles}
Each experiment varies one factor and holds the others fixed. Arms are paired: the same terrain seed and release state are flown under every setting. Seed lists are written to files before the runs and are not reused for tuning. Every result file stores the git commit, the active landing criterion, the Isaac Sim version, the GPU and driver, the seed list and the controller gains.

\subsection{Experiments}\label{sec:experiments}
Table~\ref{tab:experiments} lists the experiments. E0 repeats identical seeds to measure the simulator's repeatability (the noise floor). E1 and E2 are geometric: they raycast the Isaac collision surface and need no landing episodes, so they can use many seeds. E3 and E5 fly episodes under changed settings. E4 re-scores stored touchdown states under alternative criteria, so it costs no new episodes. E6 measures cost.

\subsection{Statistics}\label{sec:stats}
Binary landing outcomes are paired by seed and compared with McNemar's exact test; we report the discordant counts, the difference in rates and a 95\,\% bootstrap interval. Continuous geometric measures are compared with the Wilcoxon signed-rank test on per-seed log ratios, which stays valid when two methods coincide analytically and the difference has near-zero variance.
